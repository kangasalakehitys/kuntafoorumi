# Yleiskatsaus kuntafoorumista
Moderni verkkopalvelu joka skaalautuu mobiiliin ja web-verkkosivuksi. Kuntapäättäjät, johtajat ja kuntatiedosta kiinnostuneet asiantuntijat sekä opiskelijat voivat keskustella kuntatiedosta ja ajankohtaisista kunta-asioista.

## Arkkitehtuuri ja rakenne
Sivusto on yksikertainen muutaman sivun palvelun, joka tarjoaa linkit ja keskustelualustan kuntatiedolle.

## Code Style & Rules
- Use two-space indentation.
